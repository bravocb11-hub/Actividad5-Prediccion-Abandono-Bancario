# Guía para incorporar tus archivos modificados

1. Copia tu notebook `.ipynb` (con el nombre elegido) en `notebooks/`.
2. Copia el ZIP de resultados y evidencias (con el nombre elegido) en `evidencias/` si pesa menos de 25 MiB para subirlo por navegador.
3. No es necesario cambiar los nombres de los archivos.
4. Si quieres que el README general enlace al notebook directamente, reemplaza la descripción genérica por su nombre real.
5. Sube el contenido de esta carpeta a GitHub, no el ZIP del paquete como único archivo.
6. Comprueba que cada directorio muestre su README y que los enlaces a los archivos funcionen.
