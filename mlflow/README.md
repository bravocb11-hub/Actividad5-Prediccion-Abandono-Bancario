# Seguimiento experimental con MLflow

`resumen_experimentos.json` documenta los resultados exportados de las ejecuciones. El notebook configura un backend SQLite y guarda parámetros, métricas y artefactos.

**Importante:** esta carpeta no contiene la base `mlflow.db` ni todos los archivos `mlartifacts` del ZIP de Colab. El archivo completo debe conservarse como evidencia adicional; no confundir el resumen con una instancia MLflow restaurable.

Para mostrar evidencias visuales, iniciar MLflow en Colab o en el entorno de ejecución y guardar capturas de la lista de runs, métricas, parámetros y artefactos. Añadirlas aquí, evitando rutas o credenciales privadas.

El respaldo ZIP renombrado, cuando se publique, se encuentra en `../evidencias/`.
