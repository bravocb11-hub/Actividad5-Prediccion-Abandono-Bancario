# Evidencias de ejecución

Coloca aquí el ZIP de evidencias renombrado que tienes en tu PC, si pesa menos de 25 MiB para subirlo desde la interfaz web de GitHub. No descomprimas automáticamente la base de MLflow ni los modelos si contienen archivos grandes.

El ZIP debe incluir los resultados y los artefactos de MLflow generados por el notebook. Verifica que no contenga credenciales, tokens o datos privados. Si el ZIP supera el límite web, usa Git LFS o entrega el ZIP por separado y documenta el enlace autorizado.
