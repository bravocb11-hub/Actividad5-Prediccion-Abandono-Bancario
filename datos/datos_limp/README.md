# Datos depurados

- `churn_limpio_v1.csv`: versión depurada usada en el experimento.

La lógica de preparación está en el notebook. Antes de reutilizar el dataset, comprobar tipos, duplicados, valores ausentes y correspondencia con los metadatos. Las transformaciones aprendidas (como el escalado) deben ajustarse solo con los datos de entrenamiento.
