# Datos del proyecto

Esta carpeta separa el conjunto original de su versión depurada. Procedencia declarada: dataset público `shantanudhakadd/bank-customer-churn-prediction` de Kaggle; no son datos de clientes reales de BBVA.

- `datos_ini/`: copia original utilizada en el experimento.
- `datos_limp/`: versión depurada y metadatos de trazabilidad.

Las transformaciones y el orden de operaciones están implementados en el notebook de `../notebooks/`. El dataset de prueba se mantiene separado del ajuste de hiperparámetros. No incorporar información personal adicional.
